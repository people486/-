# 实验一 文本分类

## 1 项目说明

这是我在“当代人工智能”课程实验一中完成的新闻文本分类项目。我使用 TF-IDF 把文本转换成数字特征，然后分别训练逻辑回归和线性支持向量机，比较它们在十分类任务中的效果。

老师提供的数据中有 7368 条带标签的训练文本和 2457 条没有标签的测试文本。我把带标签的数据按 8∶2 划分成训练集和验证集，并使用分层划分，使两个集合中的类别比例尽量接近。为了让每次运行的结果一致，我把随机种子设为 42。

## 2 文件说明

### 仓库文件

- `main.py`：完整实验代码
- `README.md`：项目说明和运行方法
- `requirements.txt`：Python 依赖列表

### 运行前需要准备

课程提供的数据文件没有上传到仓库。运行代码前，需要把下面两个文件放到 `main.py` 所在目录：

- `train_data.csv`：有标签训练数据，包含 `text` 和 `target` 两列
- `test_data_unlabeled.csv`：无标签测试数据，包含 `text` 列

### 运行后生成

运行程序后会自动生成下面这些结果文件：

- `predictions_best.csv`：最终测试集预测结果
- `all_tuning_results.csv`：模型和参数对比结果
- `feature_tuning_results.csv`：TF-IDF 特征配置对比结果
- `classification_report_best.csv`：最佳模型分类结果
- `confusion_pairs_best.csv`：类别混淆统计
- `validation_errors_best.csv`：验证集错误样本
- `model_comparison.png`：模型参数对比图
- `feature_comparison.png`：特征配置对比图
- `confusion_matrix_best.png`：最佳模型混淆矩阵

## 3 环境要求

我使用 Python 3.10 完成实验，主要用到 pandas、NumPy、scikit-learn 和 Matplotlib。

可以按照下面的命令创建环境并安装依赖：

```bash
conda create -n project1 python=3.10
conda activate project1
python -m pip install -r requirements.txt
```

## 4 运行方法

确认 `main.py`、`train_data.csv` 和 `test_data_unlabeled.csv` 位于同一目录，然后在该目录执行：

```bash
python main.py
```

运行后，程序会依次完成：

1. 加载并检查数据；
2. 按照 8∶2 分层划分训练集和验证集；
3. 提取 TF-IDF 特征；
4. 比较逻辑回归和线性 SVM 的不同参数；
5. 比较不同 TF-IDF 特征配置；
6. 生成分类报告、混淆矩阵和错误分析；
7. 使用全部有标签数据训练最终模型；
8. 生成测试集预测文件。

## 5 实验设置

- 随机种子：42
- 验证集比例：20%
- 划分方式：分层随机划分
- 主要评价指标：准确率
- 辅助评价指标：Macro-F1
- 比较模型：Logistic Regression、Linear SVM
- 模型参数：`C = 0.1、1、10`
- TF-IDF 配置：
  - unigram，5000 维
  - unigram 与 bigram，5000 维
  - unigram，10000 维
  - unigram 与 bigram，10000 维

我先划分数据，再用训练集学习 TF-IDF 的词表和权重，之后用相同的规则转换验证集。这样可以避免在训练时提前使用验证集的信息。

## 6 主要实验结果

在相同的 5000 维 unigram 特征下：

| 模型 | C | 验证准确率 | Macro-F1 |
| --- | ---: | ---: | ---: |
| Logistic Regression | 10 | 0.9132 | 0.9135 |
| Linear SVM | 10 | 0.9077 | 0.9085 |

从结果可以看出，逻辑回归的验证准确率比线性 SVM 高一些，而且训练速度更快。因此，我选择逻辑回归继续进行后面的特征实验。

把 unigram 特征数量从 5000 增加到 10000 后，逻辑回归的验证准确率由 0.9132 提高到 0.9261，Macro-F1 由 0.9135 提高到 0.9265。我原本以为加入 bigram 可能会继续提升效果，但实际结果没有提高，说明更复杂的特征不一定更适合当前数据。

## 7 最终模型

最终配置为：

- 特征表示：TF-IDF
- `ngram_range=(1, 1)`
- `max_features=10000`
- 分类器：Logistic Regression
- `C=10`
- `max_iter=1000`
- `random_state=42`

选好参数后，我使用全部 7368 条带标签数据重新训练模型，再预测 2457 条测试文本。预测结果保存在 `predictions_best.csv` 中。这个文件没有表头和索引，每一行对应一条测试文本的预测类别。

由于测试集没有提供正确标签，所以无法直接计算测试集准确率。这里的 0.9261 是验证集准确率。

## 8 错误分析

最佳模型在 1474 条验证数据中错误分类 109 条。主要混淆包括：

- 类别 7 被预测为类别 2：12 条
- 类别 1 被预测为类别 2：9 条
- 类别 2 被预测为类别 7：9 条
- 类别 2 被预测为类别 0：6 条
- 类别 2 被预测为类别 1：5 条

我查看了一些预测错误的文本，发现部分文本比较短，能够表示主题的词较少。另外，原始文本中还包含邮件地址、组织名称和引用内容，这些信息也可能干扰分类。本次实验没有继续比较文本清洗前后的结果，这一点以后还可以改进。

## 9 复现说明

代码中固定了随机种子 42。在数据和依赖环境相同的情况下，应该可以得到相同的数据划分和接近的模型结果。不同电脑的性能和运行状态不同，因此训练时间可能会有变化。
